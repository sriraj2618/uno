# 🃏 UNO Card Detector AI

A professional AI-powered web application that detects and classifies UNO cards using a custom-trained YOLOv8 model.

Developed by **Madishetty Sriraj**

---

## 🚀 Features

- 🃏 Detects 54 UNO card classes
- 🤖 YOLOv8 AI Model
- 📤 Upload UNO card images
- 🖼️ Displays uploaded and detected images
- 📊 Confidence score for each prediction
- 📥 Download prediction result
- 💻 Modern Streamlit interface
- 📱 Responsive design

---

## 🛠 Technologies Used

- Python
- Streamlit
- YOLOv8 (Ultralytics)

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/UNO_Card_Detector.git
```

Move into the project folder:

```bash
cd UNO_Card_Detector
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
